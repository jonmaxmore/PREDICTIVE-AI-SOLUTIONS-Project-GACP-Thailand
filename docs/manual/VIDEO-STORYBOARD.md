## ⚠️ ก่อนตัดต่อ — ต้องรู้ก่อน

1. **แหล่งวิดีโอ = อัดต่อเนื่องทั้ง role ไม่ใช่ต่อฉาก** — walkthrough spec อัดวิดีโอ**ต่อการรัน 1 role**
   (public / farmer / reviewer / auditor / scheduler / account / admin) เป็นไฟล์เดียวยาวตลอดการไล่ทุก
   หน้าของ role นั้น ไม่ใช่คลิปสั้นแยกตามฉาก — ไฟล์อยู่ที่
   `evidence/staging-walkthrough/test-output/<ชื่อ-test>/video.webm` ผู้ตัดต่อต้อง**หาช่วงเวลาที่ตรงกับ
   แต่ละฉากเอง** โดยอ้างอิงลำดับหน้าใน `walkthrough-manifest.json` (แต่ละหน้าใช้เวลาไม่เท่ากัน ประมาณ
   3–8 วินาทีต่อหน้ารวมเวลาโหลด — ใช้เป็นตัวประมาณคร่าวๆ หาช่วงเวลาในไฟล์วิดีโอ ไม่ใช่ค่าตายตัว)
2. **ภาพชุดแรกมาจาก staging build ~22 กรกฎาคม 2026** — ฉากที่มีป้าย `[จะเปลี่ยนหลังอัปเดต]` ต้องอัดซ้ำ
   หลัง deploy build ใหม่ก่อนใช้เป็นวิดีโอฉบับเผยแพร่จริง (เหตุผลเดียวกับ
   `docs/manual/USER-MANUAL-SKELETON.md`)
3. **ฉากที่ต้องใช้ dynamic route (มี id จริง)** — walkthrough spec ไม่ถ่ายอัตโนมัติ (ไม่มีเคสให้เดา id) —
   ฉากเหล่านี้ (รายละเอียดคำขอ, ใบรับรอง, สแกน QR) **ต้อง operator อัดเพิ่มด้วยมือ** จากเคสทดสอบจริง 1
   ชุด ก่อนตัดต่อฉบับเผยแพร่
4. **ห้ามพูดเกินของจริง** — สคริปต์บรรยายด้านล่างมีวงเล็บ `(ของจริงวันนี้: ...)` กำกับจุดที่ยังไม่เปิด/ไม่
   สมบูรณ์ ต้องอ่านตามนั้น ห้ามตัดวงเล็บออกแล้วพูดเหมือนใช้งานได้ครบ (ตาม the work queue §6: "ตอบตามความ
   จริง ห้ามเกินหลักฐาน" — ใช้กับสคริปต์วิดีโอเหมือนกับคำตอบต่อผู้ชม)

## จุดหยุดอธิบาย (สรุปจากตารางบน — ไว้เตือนคนตัดต่อ/ผู้บรรยายสด)
